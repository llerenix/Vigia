Tecnología que cuida al paciente en UCI

VIGIA es un sistema IoT de bajo costo diseñado para monitorear continuamente los signos vitales de pacientes con riesgo de sepsis. Utiliza el sensor MAX30100 para medir la saturación de oxígeno en sangre y la frecuencia cardíaca, mientras que el MLX90614 mide la temperatura corporal. Una Raspberry Pi recibe y procesa estas señales en tiempo real, utilizando un modelo ligero de aprendizaje automático para estimar la presión arterial sistólica sin sensores adicionales. Los datos se transmiten mediante Wi-Fi y MQTT a la nube, donde se aplican los criterios NEWS-2 para identificar signos de alerta. Cuando se detectan patrones anormales, el personal médico recibe una alerta para intervenir oportunamente.
